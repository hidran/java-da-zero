# Lezione 107: Coerenza distribuita con le saghe

Progetto della lezione. Richiede JDK 25 e il Maven Wrapper incluso. Il primo build richiede Internet.

Esegui i test con `./mvnw test` (Windows: `mvnw.cmd test`).

Questa lezione dimostra il comportamento con test del contesto Spring; non richiede l’avvio di un server HTTP.
