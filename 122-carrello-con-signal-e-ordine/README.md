# Lezione 122: Un carrello con signal e l'ordine

Progetto full-stack alla fine della lezione: API Spring Boot in api/ (JDK 25, Docker per PostgreSQL)
e, se presente, il client Angular in web/ (Node 22.22.3+, 24.15+ o 26). Per avviarlo:

```bash
docker compose up -d
(cd api && ./mvnw spring-boot:run)
(cd web && npm ci && npm start)
```
