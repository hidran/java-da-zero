# Lezione 65: Il primo aspetto, log e tempi di esecuzione

Progetto della lezione. Richiede JDK 25 e il Maven Wrapper incluso. Il primo build richiede Internet.

Esegui i test con `./mvnw test` (Windows: `mvnw.cmd test`).

Per avviare l’applicazione: `./mvnw package`, poi `java -jar target/shop-0.0.1-SNAPSHOT.jar`. Il server ascolta sulla porta 18095. Le richieste dimostrative sono in `requests/` e nel client HTTP web incluso, `/rest-client.html`. Ferma il server con Ctrl+C.
