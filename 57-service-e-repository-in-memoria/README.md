# Lezione 57: Service layer e repository in memoria

Progetto della lezione. Richiede JDK 25 e il Maven Wrapper incluso. Il primo build richiede Internet.

Esegui i test con `./mvnw test` (Windows: `mvnw.cmd test`).

Per avviare l’applicazione: `./mvnw package`, poi `java -jar target/shop-0.0.1-SNAPSHOT.jar`. Le richieste dimostrative sono in `requests/` e nel client HTTP web incluso. Ferma il server con Ctrl+C.
